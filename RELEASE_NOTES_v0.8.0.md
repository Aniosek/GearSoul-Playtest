# GearSoul v0.8.0 — MetaHuman, autorskie narzędzia i handel regionalny

Publiczna wersja pre-alpha do testów multiplayerowych Etapów 0–70.

## Najważniejsze zmiany

- regionalne ceny tworzone wyłącznie przez zakończone transakcje prawdziwych graczy,
- fizyczne kontrakty transportowe z ładunkiem, wozem, karawaną i nagrodą w escrow,
- zoptymalizowany MetaHuman jako warstwa wizualna postaci gracza,
- autorskie kamienne narzędzia z osobnymi częściami i etapami wykonania,
- autorska kuźnia, miechy kowalskie i skrzynia warsztatowa z trzema LOD-ami,
- polska instrukcja, trzy launchery i generator paczki raportu błędu.

## Weryfikacja

- build edytora UE 5.8.1: sukces,
- automatyzacja: 73/73 testy zakończone sukcesem,
- końcowy `BuildCookRun`: `BUILD SUCCESSFUL`, kod 0,
- smoke test gotowego EXE: kod 0, MetaHuman i animacja gotowe, mapa załadowana, zapis zatwierdzony,
- paczka sprawdzona pod kątem obecności EXE, launcherów, instrukcji i licencji,
- archiwum nie zawiera logów, zapisów gry ani edytowalnych źródeł MetaHumana.

## Instalacja

1. Pobierz ZIP i rozpakuj go w całości.
2. Uruchom `START_GearSoul_Solo.bat`, `START_GearSoul_Host.bat` albo `START_GearSoul_Join.bat`.
3. Nie uruchamiaj EXE bezpośrednio z wnętrza archiwum.
